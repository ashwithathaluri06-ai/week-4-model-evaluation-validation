## 📊 Evaluation Metrics

### Classification Metrics
- **Accuracy:** Measures the proportion of correct predictions.
- **Precision:** Measures how many predicted positive cases are actually positive.
- **Recall:** Measures how many actual positive cases are correctly identified.
- **F1-score:** Balances precision and recall.
- **ROC-AUC:** Evaluates the model's ability to rank positive examples above negative examples.
- **Confusion Matrix:** Summarizes true positives, true negatives, false positives, and false negatives.

### Regression Metrics
- **MAE:** Mean Absolute Error.
- **MSE:** Mean Squared Error.
- **RMSE:** Root Mean Squared Error.
- **R² Score:** Measures model performance relative to a mean-prediction baseline.

## 🔍 Validation Techniques

This project explains the following validation methods:

1. Train-test split
2. Stratified sampling
3. K-fold cross-validation
4. Stratified k-fold cross-validation
5. Time-series validation
6. Group-aware validation

The choice of validation technique depends on dataset size, class distribution, and the relationship between observations.
